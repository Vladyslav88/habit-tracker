# Habit Tracker

Особистий трекер двох звичок, **тренування** + **англійська**, у вигляді Telegram Mini App.
Інтерфейс українською, дизайн змінюється з сезоном і часом доби.

- Повне ТЗ: [SPEC.md](SPEC.md)
- Що зробити руками (GitHub Pages, BotFather, перевірка): [CHECKLIST.md](CHECKLIST.md)
- Історія змін: [CHANGELOG.md](CHANGELOG.md)

## Стан

| Етап | Що | Статус |
|---|---|---|
| 1 — ядро | сховище (CloudStorage + localStorage), розклад і паузи, «Сьогодні», календар, сезонний дизайн | ✅ |

## Як це влаштовано

- Чистий HTML/CSS/JS, **без збірки і без npm**: ES-модулі напряму в браузері.
- Хостинг на GitHub Pages з кореня репозиторію.
- Дані в `Telegram.WebApp.CloudStorage` (синхронізація між пристроями). Поза Telegram
  працює localStorage з банером «Режим браузера».
- Усі записи йдуть через чергу: записи в один ключ зливаються, порядок зберігається,
  при помилці статус «помилка» й автоповтор. Швидкі повторні тапи нічого не гублять.

```
index.html
css/base.css        нейтральні токени, кнопки, поля, шторки
css/palette.css     сезонні палітри звичок і акцент (світла/темна тема)
css/decor.css       небо за часом доби, сезонні сцени, частинки
css/views.css       екрани
js/app.js           вхід: тема, вкладки, годинник
js/tg.js            обгортка Telegram.WebApp (BackButton, Haptic, кольори)
js/storage.js       адаптер сховища + черга записів (set / remove / update — запис зі злиттям)
js/store.js         записи, налаштування, початкова історія, упаковка старих місяців
js/schedule.js      розклад (з версіями), паузи, стани днів
js/analytics.js     розрахунки аналітики, контрольних точок і місячної картки (чисті функції, правила як у календарі)
js/achievements.js  досягнення: перелік, умови, прогрес (чисті функції)
js/entry.js         схема записів і довідники
js/dates.js         дати й українські формати
js/seasons.js       сезони, час доби, превʼю, частинки
js/scenes.js        SVG-сцени шапки (гарбузи, сніговик, квіти, соняшники)
js/ui/…             екрани й компоненти (ui/analytics.js — вкладка, ui/checkpoints.js — точки,
                    ui/month.js — місячна картка, ui/achievements.js — досягнення і показ нового)
assets/icon.svg
tests/              тести в Node (синхронізація досягнень)
```

## Локальний запуск

```sh
python3 -m http.server 8000
# відкрий http://localhost:8000
```

Тести (Node 22+, без npm): `node --test tests/*.test.mjs`.

Превʼю сезонів: `?season=winter&time=night&garland=1` (або **Налаштування → Про застосунок**). Не зберігається: банер «Вийти» або перезавантаження.
