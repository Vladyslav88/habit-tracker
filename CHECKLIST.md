# Чекліст: що зробити руками

Коротко й по кроках. Назви кнопок у GitHub і BotFather іноді трохи змінюються: якщо щось називається інакше, шукай найближче за змістом.

---

## 0. Подивитися локально на Mac (необовʼязково)

1. Відкрий Terminal у папці репозиторію.
2. Запусти: `python3 -m http.server 8000`
3. Відкрий у браузері http://localhost:8000
4. Зверху має бути жовтий банер «Режим браузера, дані лише на цьому пристрої». Дані зберігаються в localStorage цього браузера.

> Просто двічі клікнути по `index.html` не вийде: браузер не завантажує модулі з `file://`, тому потрібен локальний сервер.

Корисне для перевірки дизайну: `http://localhost:8000/?season=winter&time=night`
(season: `autumn` / `winter` / `spring` / `summer`, time: `morning` / `day` / `evening` / `night`).
Те саме є в застосунку: **Налаштування → Про застосунок → Превʼю дизайну**.

## 1. GitHub Pages (хостинг застосунку)

1. Спочатку змерджи PR Етапу 1 у `main`.
2. GitHub → репозиторій `habit-tracker` → **Settings** → **Pages**.
3. **Source**: `Deploy from a branch`. **Branch**: `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини там зʼявиться адреса. Має бути
   `https://vladyslav88.github.io/habit-tracker/`. Відкрий її: має завантажитися застосунок із жовтим банером.

Нюанси:
- Якщо репозиторій **приватний**, Pages працює лише на платному плані GitHub (Pro/Team). На безкоштовному плані репозиторій має бути публічним. Секретів у коді немає, тож публічний репозиторій безпечний.
- Після кожного мерджу в `main` сайт оновлюється сам. GitHub кешує файли до ~10 хвилин, тому нова версія може зʼявитися не одразу.

## 2. Бот у @BotFather

1. У Telegram відкрий **@BotFather** → `/newbot`.
2. Імʼя: `Habit Tracker`. Username: будь-який вільний, що закінчується на `bot` (напр. `vlad_habits_bot`).
3. BotFather надішле **токен**. ⚠️ **Нікуди його не вставляй і не комить у репо.** Збережи в менеджері паролів: знадобиться лише в Етапі 3 (Cloudflare Worker).
4. **Кнопка меню** (головний спосіб відкривати застосунок):
   `/mybots` → вибери бота → **Bot Settings** → **Menu Button** → **Configure menu button** →
   надішли URL `https://vladyslav88.github.io/habit-tracker/` → надішли назву кнопки, напр. `Трекер`.
5. **Main Mini App** (необовʼязково, але зручно: кнопка «Відкрити» в профілі бота):
   `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → той самий URL.
6. Відкрий чат із ботом → натисни **Start**. Ліворуч від поля вводу зʼявиться кнопка меню → тапни її.

## 3. Перевірка Етапу 1

**На iPhone (Telegram):**
- [ ] Застосунок відкривається на весь екран, **жовтого банера немає**, угорі справа «збережено».
- [ ] Картка сьогоднішньої звички: пн/ср/пт тренування, вт/чт англійська, у вихідні «Сьогодні вихідний» і наступна звичка з датою.
- [ ] «Виконав» → знизу виїжджає покрокова форма (тренування: тривалість → спина → енергія → коментар; англійська: тема → домашка → енергія → коментар). Кожен крок можна пропустити. «Не виконав» → чипи причин.
- [ ] Системна кнопка «Назад» у шапці Telegram закриває шторку.
- [ ] Легка вібрація при відмітці.
- [ ] Кнопка «+ бонус» → «+ Тренування» → зʼявляється картка з позначкою «Бонус».
- [ ] Календар: 25 і 28 вересня залиті помаранчевим (початкова історія), 29 з рамкою «сьогодні». Свайп вліво/вправо гортає місяці.
- [ ] Тап по дню → деталі → «Редагувати» → зміни → «Зберегти». Видалення питає підтвердження.
- [ ] Налаштування → Паузи → додай паузу на кілька днів → у календарі ці дні заштриховані.
- [ ] Налаштування → Розклад → зміни щось → «Зберегти» → «Сьогодні» і календар оновилися.
- [ ] Перемкни тему Telegram (світла/темна): застосунок перемикається теж.

**На Mac (Telegram Desktop):**
- [ ] Відкрий того ж бота: відмітки з iPhone на місці (синхронізація через хмару Telegram).
- [ ] Зроби відмітку на Mac → закрий і знову відкрий застосунок на iPhone → вона є.

**Звичайний браузер:**
- [ ] Відкрий адресу Pages у Safari/Chrome: жовтий банер, дані лише в цьому браузері й не змішуються з Telegram.

## 4. Якщо щось пішло не так

- **Стара версія після оновлення.** Повністю закрий застосунок і відкрий знову. Якщо не допомогло, зачекай ~10 хвилин (кеш GitHub Pages).
- **Статус «помилка» вгорі.** Застосунок сам повторює запис. Тап по статусу показує причину і запускає повтор одразу. Поки є незбережені зміни, Telegram спитає підтвердження перед закриттям.
- **Подивитися консоль (для налагодження).** Telegram Desktop: Settings → Advanced → Experimental settings → *Enable webview inspecting*, потім правий клік у застосунку → Inspect. На iPhone: debug-меню Telegram (10 тапів по іконці Settings) → *Allow Web View Inspection*, далі Safari на Mac → Develop. Пункти меню можуть відрізнятися між версіями Telegram.
