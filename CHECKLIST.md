# Чекліст: що зробити руками

Коротко й по кроках. Назви кнопок у GitHub і BotFather іноді трохи змінюються: якщо щось називається інакше, шукай найближче за змістом.

---

## 0. Подивитися локально на Mac (необовʼязково)

1. Відкрий Terminal у папці репозиторію.
2. Запусти: `python3 -m http.server 8000`
3. Відкрий у браузері http://localhost:8000
4. Зверху має бути жовтий банер «Режим браузера, дані лише на цьому пристрої». Дані зберігаються в localStorage цього браузера.

> Просто двічі клікнути по `index.html` не вийде: браузер не завантажує модулі з `file://`, тому потрібен локальний сервер.

### Превʼю сезонів

Посилання відкривають «Сьогодні» в потрібному сезоні й часі доби (працюють після того, як сайт на Pages оновився; локально заміни початок на `http://localhost:8000/`):

| Сезон | | |
|---|---|---|
| 🍂 Осінь | [день](https://vladyslav88.github.io/habit-tracker/?season=autumn&time=day) | [ніч](https://vladyslav88.github.io/habit-tracker/?season=autumn&time=night) |
| ❄️ Зима (вночі з гірляндою) | [день](https://vladyslav88.github.io/habit-tracker/?season=winter&time=day) | [ніч](https://vladyslav88.github.io/habit-tracker/?season=winter&time=night&garland=1) |
| 🌸 Весна | [день](https://vladyslav88.github.io/habit-tracker/?season=spring&time=day) | [ніч](https://vladyslav88.github.io/habit-tracker/?season=spring&time=night) |
| ☀️ Літо | [день](https://vladyslav88.github.io/habit-tracker/?season=summer&time=day) | [ніч](https://vladyslav88.github.io/habit-tracker/?season=summer&time=night) |

Параметри: `season` = `autumn` / `winter` / `spring` / `summer`, `time` = `morning` / `day` / `evening` / `night`, `garland=1` вмикає гірлянду.
Превʼю **не зберігається**: вгорі банер «Превʼю … · Вийти», а параметри одразу зникають з адреси, тож перезавантаження теж повертає реальний сезон.
Календар на превʼю не реагує: він завжди в палітрі місяця, що переглядається. Щоб побачити зимову палітру календаря, догортай до грудня.
Те саме превʼю є в застосунку (зручно в Telegram): **Налаштування → Про застосунок → Превʼю дизайну**.

## 1. GitHub Pages (хостинг застосунку)

1. Спочатку змерджи PR Етапу 1 у `main`.
2. GitHub → репозиторій `habit-tracker` → **Settings** → **Pages**.
3. **Source**: `Deploy from a branch`. **Branch**: `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини там зʼявиться адреса. Має бути
   `https://vladyslav88.github.io/habit-tracker/`. Відкрий її: має завантажитися застосунок із жовтим банером.

Нюанси:
- Якщо репозиторій **приватний**, Pages працює лише на платному плані GitHub (Pro/Team). На безкоштовному плані репозиторій має бути публічним. Секретів у коді немає, тож публічний репозиторій безпечний.
- Після кожного мерджу в `main` сайт оновлюється сам. GitHub кешує файли до ~10 хвилин, тому нова версія може зʼявитися не одразу.

## 2. Бот у @BotFather

1. У Telegram відкрий **@BotFather** → `/newbot`.
2. Імʼя: `Habit Tracker`. Username: будь-який вільний, що закінчується на `bot` (напр. `vlad_habits_bot`).
3. BotFather надішле **токен**. ⚠️ **Нікуди його не вставляй і не комить у репо.** Збережи в менеджері паролів: знадобиться лише в Етапі 3 (Cloudflare Worker).
4. **Кнопка меню** (головний спосіб відкривати застосунок):
   `/mybots` → вибери бота → **Bot Settings** → **Menu Button** → **Configure menu button** →
   надішли URL `https://vladyslav88.github.io/habit-tracker/` → надішли назву кнопки, напр. `Трекер`.
5. **Main Mini App** (необовʼязково, але зручно: кнопка «Відкрити» в профілі бота):
   `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → той самий URL.
6. Відкрий чат із ботом → натисни **Start**. Ліворуч від поля вводу зʼявиться кнопка меню → тапни її.

## 3. Перевірка Етапу 1

**На iPhone (Telegram):**
- [ ] Застосунок відкривається на весь екран, **жовтого банера немає**, угорі справа «збережено».
- [ ] Картка сьогоднішньої звички: пн/ср/пт тренування, вт/чт англійська, у вихідні «Сьогодні вихідний» і наступна звичка з датою.
- [ ] «Виконав» → знизу виїжджає покрокова форма (тренування: тривалість → спина → енергія → коментар; англійська: тема → домашка → енергія → коментар). Кожен крок можна пропустити. «Не виконав» → чипи причин.
- [ ] Системна кнопка «Назад» у шапці Telegram закриває шторку.
- [ ] Невибрані чипи причин і кнопки енергії виглядають як кнопки (фон + рамка).
- [ ] Легка вібрація при відмітці.
- [ ] Кнопка «+ бонус» → «+ Тренування» → зʼявляється картка з позначкою «Бонус».
- [ ] Кольори сезону яскраві й у темній темі: восени тренування гарбузове, англійська сливова; кнопки в тонах сезону.
- [ ] Календар: гортай вересень → грудень → березень → червень. Кожен сезон видно одразу навіть у порожньому місяці: кольорова смужка зверху картки, заголовок і мітка сезону («❄️ Зима»), кільця «заплановано», легенда і доріжки «Підсумку місяця» змінюють колір. Від превʼю це не залежить.
- [ ] Шапка «Сьогодні»: сцена сезону (восени гарбузи, купки листя, руде дерево); увечері й уночі гарбузи світяться. Під пагорбами немає світлої смуги ні в світлій, ні в темній темі.
- [ ] Календар: 25 і 28 вересня залиті кольором тренування (початкова історія), 29 з рамкою «сьогодні». Тренування — кола, англійська — квадрати. Свайп вліво/вправо гортає місяці; у грудні палітра й фон стають зимовими.
- [ ] Легенда під календарем: «заплановано» і «пауза» добре видно; є пункт «дві звички в один день».
- [ ] День із двома звичками (напр. англійська + бонусне тренування) показує номер і дві маленькі мітки: коло й квадрат.
- [ ] Тап по дню → деталі → «Редагувати»: редактор відкривається **у тій самій шторці**, зʼявляється «назад»; «Назад» (у шторці чи в Telegram) повертає до деталей дня.
- [ ] Відміть пропуск за якийсь минулий день → Налаштування → Паузи → додай паузу, що його накриває → зʼявиться «Перетворити пропуски на паузу?». «Перетворити»: пропуск зникне, день заштрихований. «Залишити»: день теж заштрихований, а в шторці дня пропуск видно з позначкою «Не рахується».
- [ ] Дні паузи в календарі помітно заштриховані.
- [ ] Налаштування → Розклад → зміни щось → «Зберегти» → «Сьогодні» і календар оновилися.
- [ ] Перемкни тему Telegram (світла/темна): застосунок перемикається теж.

**На Mac (Telegram Desktop):**
- [ ] Відкрий того ж бота: відмітки з iPhone на місці (синхронізація через хмару Telegram).
- [ ] Зроби відмітку на Mac → закрий і знову відкрий застосунок на iPhone → вона є.

**Звичайний браузер:**
- [ ] Відкрий адресу Pages у Safari/Chrome: жовтий банер, дані лише в цьому браузері й не змішуються з Telegram.

## 3а. Перевірка Етапу 2а (аналітика, v0.3.0)

Нічого налаштовувати не треба — лише подивитися.
- [ ] Налаштування → Про застосунок: версія **0.3.0 · Етап 2а**.
- [ ] Вкладка «Аналітика»: угорі найближча контрольна точка з відліком (наприкінці вересня — «Міні-чек, 10 жовтня, через N днів»).
- [ ] Перемикач «4 тижні / Місяць / 3 місяці / Усе» змінює діапазон дат під ним. Поки історія коротка, усі періоди починаються з 25 вересня (підписано «відстеження з 25 вересня»).
- [ ] Поки даних мало — плашка «Даних поки мало», а в картках тривалості, спини й енергії замість графіків пояснення «зʼявиться після 3» і смужка прогресу. Це нормально.

- [ ] Додай паузу, що накриває минулий пропуск («Залишити») → пропуск зникає з % і з «Причин пропусків», як і в календарі.
- [ ] Налаштування → Контрольні точки: є «Міні-чек» і «Ревʼю» (7–8 листопада). «Додати точку» → назва, дата (або «Кілька днів») → точка зʼявляється і в Аналітиці. Кошик видаляє.
- [ ] Світла й темна тема: картки й графіки читаються.

## 4. Якщо щось пішло не так

- **Стара версія після оновлення.** Повністю закрий застосунок і відкрий знову. Якщо не допомогло, зачекай ~10 хвилин (кеш GitHub Pages).
- **Статус «помилка» вгорі.** Застосунок сам повторює запис. Тап по статусу показує причину і запускає повтор одразу. Поки є незбережені зміни, Telegram спитає підтвердження перед закриттям.
- **Подивитися консоль (для налагодження).** Telegram Desktop: Settings → Advanced → Experimental settings → *Enable webview inspecting*, потім правий клік у застосунку → Inspect. На iPhone: debug-меню Telegram (10 тапів по іконці Settings) → *Allow Web View Inspection*, далі Safari на Mac → Develop. Пункти меню можуть відрізнятися між версіями Telegram.
